# Чек-лист инициализации нового проекта

Одноразовый чек-лист для нового репозитория из шаблона. После прохождения — удалить файл.

## 1. Описание проекта

Заполнить раздел «Описание проекта» в `AGENTS.md`:

- Название и назначение
- Цели пользователя/команды
- Сценарии использования и аудитория
- Контекст и ограничения

## 2. Окружение

Применить `agent_docs/guides/environment-setup.md`:

- `.vscode/settings.json` — видимость `.env` в IDE
- `.cursorignore` — скрыть секреты от AI-агентов
- `.gitignore` — `.env*` уже добавлен в шаблоне
- `.env.example` — шаблон переменных

## 3. Глоссарий

Заполнить `agent_docs/glossary.md` начальной терминологией: специфичные термины, аббревиатуры, кодовые названия, ссылки на внешние ресурсы.

## 4. Архитектура (если применимо)

Заполнить `agent_docs/architecture.md` или удалить, если структура проекта тривиальна и не требует описания.

## 5. Очистить шаблон

- Удалить этот файл (`agent_docs/setup-checklist.md`).
- Удалить `skill-andMCPupdater-zvasil/`, если не используется.
- Обновить `README.md` под содержание своего проекта.
